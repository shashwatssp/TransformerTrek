# TransformerTrek

An interactive, animation-rich educational website that explains how transformers, large language models (LLMs), and AI agents actually work.

## What's inside

TransformerTrek walks learners through:

- **AI fundamentals**, the concepts underneath everything
- **LLM internals**, tokenization, embeddings, attention, and generation, visualized step by step
- **Agents & protocols**, MCP (Model Context Protocol), A2A (Agent-to-Agent), LangGraph, and ADK
- **Evaluations**, how model quality is measured
- **Vector search**, embeddings in retrieval systems

## Tech stack

- [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vite.dev/) for the build toolchain
- [Tailwind CSS v4](https://tailwindcss.com/) for styling
- [Motion](https://motion.dev/) for animation
- [@xyflow/react](https://reactflow.dev/) for node graphs
- [Recharts](https://recharts.org/) for data visualization
- [three.js](https://threejs.org/) + [@react-three/fiber](https://docs.pmnd.rs/) for 3D scenes

## Getting started

```bash
# Install dependencies
npm install

# Start the dev server
npm run dev

# Build for production
npm run build
```
